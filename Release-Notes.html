2.0 (3) - Matching Vision Pro Companion and plugin

November 3, 2026. Developer ID signed, notarized by Apple, ticket stapled and Gatekeeper verified. Companion, uninstaller and bundled plugin identify as 2.0 (3), matching headset version 2.0 (3). The headset update has been uploaded to Apple but is not yet released on the App Store.

  • Updated hand-flight plugin supports proximity-based sidestick and steering controls with lease/watchdog protection. Hardware-free operation depends on aircraft configuration and is not guaranteed.
  • ISCS preparation discovers or opens the source window once, with consent, source selection and foreground guidance. Remote clicks use fresh single-use picture tickets and the real Mac pointer.
  • Optional X-Plane application audio streaming, improved instrument setup/recovery and separate Vision Pro product ownership.
  • Includes an uninstaller that reviews this product's app/plugin locations and moves selected items to Trash, with preferences and backups optionally retained.
  • Release/build identifiers align with the headset's thrust feedback guard and paired Retracted/On landing-light controls. These two receiver changes do not add a new simulator protocol.

Quit X-Plane and Companion before installing. Open Companion and run Setup > Install / Update Plugin before restarting X-Plane. The installer does not update a running simulator or grant permissions. Before you install

Install Companion on your Mac and XPPanelsVR separately from the Vision Pro App Store. The Mac installer uses Developer ID signing and notarization; the headset app uses App Store review. Keep system security enabled. Permissions may need to be granted again when updating a differently signed local build.

Connect on a trusted private network without internet port forwarding. See the network setup guide for access controls and local transport details. The optional virtual monitor uses a private macOS interface; physical-display capture is available if an OS update affects it.

The tested live configuration is Apple silicon, X-Plane 12.4.3 and ToLiss A320 v1.2.1. Build, installer and offline regression checks also cover this package. Intel, A321, X-Plane 11 and other configurations have not been verified. Up to 5120 x 1440 at a target 30 fps is a quality setting; actual performance depends on your Mac, simulator settings and network.
