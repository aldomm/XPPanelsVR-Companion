Release notes

0.1.1 testing preview

October 1, 2026. macOS 15 or later, universal Apple silicon / Intel binary. Runtime qualification remains Apple silicon only.

  • Rebuilt the bundled XPPanelsBridge plugin with renewable rudder-trim left/right commands, explicit release, opposite-direction cancellation and automatic expiry.
  • Setup now identifies a stale installed plugin by version and payload hash. After installing Companion, choose Install / Update Plugin with X-Plane closed.
  • Includes the current Display Bridge branding, shared instrument encoder, Please wait feedback, corrected popup sizing/placement and completed-frame SDR outside-video capture.
  • App, plugin manifest and package versions are synchronized. Downloads include SHA-256 checksums and machine-readable package metadata.

Before testing

This public preview is not Developer ID signed or notarized. The installer is unsigned; app/plugin signatures are ad hoc. Permissions may need to be granted again when updating a differently signed local build. This package is not a Windows installer and does not include XPPanelsVR for Vision Pro.

Use only a trusted private LAN. HTTP/video and simulator UDP are unencrypted; address consent is not secure pairing. No internet port forwarding. The optional virtual monitor uses a private macOS interface. Intel, X-Plane 11, A321 and other simulator/aircraft versions require further testing.

The verified live configuration is Apple silicon, X-Plane 12.4.3 and ToLiss A320 v1.2.1. This package revision has build and offline regression coverage, not a new sustained-flight qualification. Up to 5120 x 1440 at a target 30 fps is a quality setting, not a performance guarantee.
