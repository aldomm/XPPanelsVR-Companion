Included in this version

macOS 15 or later, universal Apple silicon / Intel binary. Runtime qualification remains Apple silicon only.

  • Rebuilt the bundled XPPanelsBridge plugin with renewable rudder-trim left/right commands, explicit release, opposite-direction cancellation and automatic expiry.
  • Setup now identifies a stale installed plugin by version and payload hash. After installing Companion, choose Install / Update Plugin with X-Plane closed.
  • Includes the current Display Bridge branding, shared instrument encoder, Please wait feedback, corrected popup sizing/placement and completed-frame SDR outside-video capture.
  • App, plugin manifest and package versions are synchronized. Downloads include SHA-256 checksums and machine-readable package metadata.

Before you install

Install Companion on your Mac and XPPanelsVR separately from the Vision Pro App Store. The Mac installer uses Developer ID signing and notarization; the headset app uses App Store review. Keep system security enabled. Permissions may need to be granted again when updating a differently signed local build.

Connect on a trusted private network without internet port forwarding. See the network setup guide for access controls and local transport details. The optional virtual monitor uses a private macOS interface; physical-display capture is available if an OS update affects it.

The tested live configuration is Apple silicon, X-Plane 12.4.3 and ToLiss A320 v1.2.1. Build, installer and offline regression checks also cover this package. Intel, A321, X-Plane 11 and other configurations have not been verified. Up to 5120 x 1440 at a target 30 fps is a quality setting; actual performance depends on your Mac, simulator settings and network.
