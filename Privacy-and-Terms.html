Local processing

ScreenCaptureKit captures recognized simulator windows after permission and Start Sharing. Outside video is separately enabled. Local popup-position telemetry identifies instruments. Approved LAN clients can receive these images. The optional local preview captures the selected whole display. No microphone or audio is captured.

Open Missing Displays sends the supported aircraft's instrument-popup commands locally when you request it. Optional Accessibility permission allows sizing and moving identified simulator instrument windows to your selected Mac display, including checked native-title-bar and resize-corner mouse drags when X-Plane does not expose movable accessibility windows. It is not required for capture, the preview or popup opening. The app does not record keystrokes or use Accessibility to inspect other applications. You may revoke this permission in macOS Privacy settings.

Sharing starts off. Address approvals are session-only and revoked when sharing stops. Current HTTP and UDP are not encrypted. IP approval is not cryptographic authentication; a reused address may belong to a different device. The command plugin and native simulator UDP interfaces are not protected by video approvals. Use only a trusted private network without internet port forwarding.

Settings, plugin receipts and recovery backups stay on the Mac. Bridge logs remain in the user's Library/Logs directory and can contain window titles, IDs and technical errors. The diagnostic report is saved only where you choose; review it before emailing support. No analytics, advertising, automatic diagnostic upload or publisher account is included.

Delete the application to stop using it; use Settings to unregister login startup and remove the plugin first. Saved settings, logs and backups may remain until you delete them. Emailing support sends your message and attachments to the support mailbox provider; do not include sensitive data unnecessarily.
