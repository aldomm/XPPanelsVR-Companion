WINDOWS 11 x64 · COMPANION 2.0

From Windows to Vision Pro.

One per-user installer includes Companion, its private runtime, display/media bridge, simulator command plugin and an optional experimental curved foveated sender. No Python, compiler, Android tools or SDK download is required.

Download Windows installer

This is the Vision Pro product. For Quest use the separate Quest website. Neither product replaces the other. X-Plane, your ToLiss aircraft, a physical joystick, GPU drivers and the Vision Pro app are separate.

1. Check the computer and download

  • Use Windows 11 x64 with current graphics drivers and Windows media components. Windows N editions need Microsoft's Media Feature Pack. Windows on ARM and other GPUs/PCs are not qualified.
  • Install your licensed X-Plane 12 and ToLiss A320. Other aircraft/versions require separate verification. Detached native pop-outs are required for cockpit images.
  • Install XPPanelsVR 2.0 on Apple Vision Pro through its App Store listing. Connect Vision Pro using Wi-Fi to your trusted private network. The PC may use Ethernet or Wi-Fi. No USB connection or router port forwarding is needed.
  • Download the installer and checksums from this release. In PowerShell run Get-FileHash "$HOME\Downloads\XPPanelsVisionProCompanion-2.0.0-build.4-windows-x64-SELF-SIGNED.exe" -Algorithm SHA256 and compare the complete value.

Companion uses one window with eight task tabs: Connection, Cockpit Displays, ISCS Tablet, Outside Video, Foveated View, Plugin Setup, Recovery, Help. Verify the publisher and file. Previous installers remain available.

Free self-signing: the package identifies AldoApps with a self-signed certificate, which Windows does not automatically trust. It is not Microsoft Store or CA-trusted signing. The public certificate is provided for inspection; importing it into a trust store is not required. Keep SmartScreen, antivirus and other Windows protections enabled. If your PC blocks this preview under its security policy, stop and contact support rather than weakening that policy.

2. Install the Windows app

  1. Save your flight and close X-Plane. Close any Vision Pro Companion version. Leave Quest's installation alone.
  2. Run the verified EXE and review its terms, including the separate NVIDIA terms for experimental streaming. Install for your own Windows account. No administrator-only service or driver is installed.
  3. Open XPPanels Vision Pro Companion 2.0 from its Desktop or Start menu shortcut. Installation does not start the simulator, sharing or the experimental sender.

The normal location is %LOCALAPPDATA%\Programs\XPPanels Vision Pro Companion\2.0.0-build.4. Settings and logs use their own %LOCALAPPDATA%\XPPanels Vision Pro Companion folder. Verified inactive older Vision Pro versions are archived under the product's Rollback folder. Active or altered versions are preserved for review; do not launch a rollback copy alongside the current app.

3. Install its simulator plugin

  1. Choose the actual X-Plane.exe you will use. Keep X-Plane closed and sharing stopped.
  2. Open Plugin Setup. Choose Check Vision Pro plugin, then Install / Update. This explicitly installs only XPPanelsVisionProBridge; it keeps a verified backup of a managed previous version.
  3. If an unowned or legacy plugin is refused, retain it and contact support for a reviewed migration. Do not rename another plugin or overwrite the Quest bridge. Installing the desktop app alone does not update the simulator plugin.
  4. Start X-Plane and load your ToLiss aircraft in ordinary desktop mode with native VR off. Its log should identify XPPanelsVisionProBridge UDP 49002. A file check confirms the disk copy, not which binary the simulator has loaded.

4. Start standard sharing first

  1. Find the PC's private IPv4 address in Windows network settings or ipconfig. On Vision Pro, Settings → Wi-Fi → the connected network's information button shows its IPv4 address. Enter the PC address and the approved Vision Pro address in Companion.
  2. In Vision Pro's simulator connection settings choose Custom JSON, that PC address and command port 49002. Set cockpit media/display port to 49200. Use the headset's Reconnect. Native UDP mode is not qualified for the separated Windows product because some timed commands still use the old bridge route.
  3. Click Start Vision Pro sharing. Review any Windows firewall request for your trusted private network. Do not create broad public-network rules or disable the firewall. Address approval is not encrypted pairing; use devices/networks you trust.
  4. Open Cockpit Displays → Prepare windows. ToLiss must be configured once to use detached native windows. The button opens/identifies Captain/FO PFD and ND, upper/lower ECAM, MCDU 1/2 and ISIS, plus ISCS when included. Healthy sources are preserved. Use the explicit Reset option to close/reopen them, or instrument mapping to repair an individual source. If ISIS opens inside the simulator, detach it before retrying.
  5. For normal outside video enable Allow H.264 outside video, refresh the headset's source list and select the main X-Plane scenery window. Start at 720p/30, then compare 1080p/30 or 1440p/30. A larger stream cannot add detail beyond X-Plane's rendered source; performance depends on the GPU and Wi-Fi. HEVC/5K modes are not supported by this standard Windows path.

After changing simulator sessions, refresh and reselect the source. If an instrument remains frozen after a host restart, toggle that instrument off/on in the headset. Seeing images or feedback does not prove that commands are being sent. If controls stop, use Vision Pro Settings → Simulator Connection → Reconnect. The current receiver does not poll the Companion's optional reconnect-request queue.

5. ISCS tablet and simulator audio

ISCS sharing is allowed by default; you can switch it off in ISCS Tablet and that choice is remembered. Sharing starts only after you press Start Vision Pro sharing. Press ISCS on the headset EFB: Companion identifies the detached panel, opens it if needed, and activates it once, moving the cursor when the desktop is idle. It does not continually force focus. Manual source selection remains available if recognition is uncertain.

Automatic ISCS header recognition requires the Windows English OCR language component. If unavailable, use manual selection or add the component through Windows Settings. A panel opened inside X-Plane must be detached first. Tablet input shares the PC mouse: pause physical mouse/keyboard use while tapping, and bring ISCS forward again if you switch apps. Connection or fresh-window checks can reject unsafe/stale input.

Use the headset audio control to request X-Plane application sound through the standard Companion media path. No microphone or CloudXR virtual audio driver is installed. Start sharing and select the current simulator process first.

6. Optional experimental foveated curved screen

Included, opt-in and experimental. The package contains the adapted curved sender, CloudXR Runtime 6.2.3, Stream Manager 6.1.0, their private DLLs and licence notices. It installs no NVIDIA audio driver, SDK headers, compiler or system OpenXR runtime selection. Supported NVIDIA hardware/drivers and a compatible XPPanelsVR Foveated receiver are required; check NVIDIA's requirements. Pairing/streaming uses additional runtime-managed network traffic; the separate session signaling port is 55010, not a complete firewall port list.

  1. Get the standard cockpit, controls and media working first. Keep native X-Plane VR off and leave pop-outs open.
  2. In Companion open Foveated View. Read the two NVIDIA licences and explicitly opt in. Refresh scenery windows, then select the main X-Plane scenery source.
  3. Choose Open experimental sender. In its separate window review the private PC address and press Start. Do not start another CloudXR session at the same time.
  4. In XPPanelsVR select Foveated Curved Screen, the PC address and 55010 explicitly. Some receiver builds still default to 55000. Do not use 55000: that is X-Plane's native stereo service and can enter VR/close detached instruments. Pair with the separate XPPanels Curved Capture host if prompted.
  5. Compare the view while keeping standard media available as a fallback. Close the sender to stop its owned session. After restarting X-Plane, close/reopen the sender with the newly selected scenery window. No automatic scene or aircraft-control replay is performed.

The current sender has fixed 11.6 m / 160° geometry for the recorded First Officer comparison; arbitrary live seat/geometry synchronization is not implemented. Headset alignment may still be needed. This is a curved scenery surface, not native stereo VR. Sharper gaze-region detail, latency, sustained frame rate, other PCs/GPUs and every headset release are not qualified. CloudXR audio/microphone streaming is disabled in this sender; use the standard Companion audio path where supported. Standard H.264, ISCS and cockpit controls remain separate.

7. Updates, rollback and removal

Companion checks the published website release once on launch. Use Help → Check for updates at any time. A notice opens no installer automatically; use the download-page button and read the headset compatibility notes. The installed headset app version is not detected. Older Windows installers remain available.

Close X-Plane and Companion before updating. The new app starts sharing off; install/update its plugin explicitly while X-Plane is closed. Existing settings are retained. Verified app rollback copies and plugin backups remain product-specific; restore an old version deliberately, never run two copies at once.

To remove the simulator plugin, close X-Plane, open this Vision Pro Companion and use Remove or Restore. Then close Companion and the experimental sender. Uninstall the exact Vision Pro app version through Windows Settings → Apps → Installed apps, or its version folder's Uninstall.exe. App uninstall preserves simulator plugins, settings, logs, rollback copies and unknown user files. It does not remove Quest, aircraft or drivers.
