Know what you are installing.

Windows Companion 2.0 is signed using AldoApps’ privately held signing key. The installer, uninstaller, Companion launcher, media bridge, control plugin and owned experimental sender executables carry the AldoApps self-signature and a DigiCert timestamp. Third-party software retains its applicable vendor signatures and licences.

What Windows will show

The signing certificate subject is CN=AldoApps XPPanels Preview. This is a self-signed certificate, not a publicly trusted certificate authority’s validation of the developer. Windows may show “Unknown publisher” or a SmartScreen reputation warning. The word Preview is the existing certificate name, including for version 2.0. Apple’s notarization applies only to the separate Mac package.

Check before you install

  1. Download through this official site and its linked GitHub release.
  2. Right-click the EXE → Properties → Digital Signatures. Inspect the AldoApps certificate and timestamp. An untrusted certificate-chain message is expected with self-signing; a hash mismatch, changed signer or missing signature is not.
  3. Compare the file’s SHA-256 against the release checksums. In PowerShell: Get-FileHash "$HOME\Downloads\XPPanelsVisionProCompanion-2.0.0-build.5-windows-x64-SELF-SIGNED.exe" -Algorithm SHA256.

Inspect the public signing certificate. It contains no private key. You do not need to import it into Windows trust stores. A matching checksum establishes the file matches this release; self-signing does not provide independent identity validation or guarantee compatibility.

Keep Windows security protections enabled. If verification fails or your PC’s security policy blocks installation, contact AldoApps support rather than weakening that policy.
