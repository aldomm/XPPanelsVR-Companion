Website privacy and credits

Updated October 15, 2026.

This static site has no analytics scripts, advertising, tracking cookies or contact forms added by AldoApps. Assets are hosted with the page; it does not load external fonts or icon services.

GitHub hosts the site and downloads. Requests disclose normal connection information to GitHub, including your IP address. GitHub may retain service and security logs under its privacy statement. This is separate from the Companion app's local processing.

The download counter requests public release totals from GitHub's API. It counts published Companion installer downloads, not unique visitors, people or successful installations. It does not set cookies, store a visitor identifier, or record clicks. GitHub receives normal connection information for this API request; credentials and the page referrer are not sent. Retired draft releases, checksums and metadata files are excluded. AldoApps may keep aggregate snapshots for download reports; these contain counts and release information, not downloader identities.

Emailing aldoapps@gmail.com sends your message and attachments to the support mailbox provider. Only send information needed for support, and review diagnostics before sharing.

The goggles artwork is the XPPanelsVR app icon, not a photograph of running software. Website icons are from Lucide; the complete licence notices are included. Application notices are available separately.
