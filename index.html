THE COMPUTER SIDE OF YOUR COCKPIT

Everything in one place.

Keep X-Plane on your Mac or Windows PC. The matching Companion brings its displays to XPPanelsVR on Vision Pro.

Outside View

Mac includes an optional virtual ultrawide monitor. Windows shares the simulator window through H.264 up to 1440p/30, with an optional experimental foveated curved sender. Windows does not install a virtual-monitor driver.

Display Bridge

Stream PFDs, NDs, ECAMs, both MCDU LCDs and ISIS from detached sources. Mac guides opening/sizing/placement; Windows provides guided preparation/reset for all nine displays and ISCS, source mapping and recovery.

Guided plugin setup

Choose your simulator folder and explicitly install its bundled command plugin. Windows owns XPPanelsVisionProBridge; Mac retains XPPanelsBridge. Managed previous versions are backed up before replacement.

Choose the installer for the computer running X-Plane. The Windows package includes its own Python runtime, media bridge, simulator plugin and experimental sender/runtime files; no compiler, SDK, ADB or separate Python download is needed. The Mac package retains its own native implementation. XPPanelsVR is available separately on the App Store for Apple Vision Pro.

Windows setup at a glance

Headset connection
Apple Vision Pro uses Wi-Fi on your trusted private network. The PC may use Ethernet or Wi-Fi. No USB or router port forwarding.
Controls and media
In XPPanelsVR choose Custom JSON, the PC address and UDP 49002; media uses TCP 49200. Receiving video does not prove controls work. Use Reconnect inside the headset.
Instruments and ISCS
Keep all nine native instrument pop-outs detached. Use Cockpit Displays → Prepare windows for the nine sources. Press ISCS on the headset EFB to find/open and activate it once; manual selection remains available. Windows shared desktop input is not independent simultaneous mouse input.
Experimental foveated
Choose Experimental foveated setup, review NVIDIA terms, select scenery and open the separate sender. Enter 55010 explicitly in the headset. Keep native VR off; 55000 is X-Plane's native stereo endpoint.

About Apple verification

XPPanelsVR for Apple Vision Pro has been approved for App Store distribution. This separate Mac Companion is distributed directly by AldoApps with Developer ID signing and Apple notarization. Notarization checks for known malicious software; it is distinct from App Store review and is not a guarantee of compatibility with every Mac or simulator configuration. Read Apple's explanation.

MAC SETUP · FROM DOWNLOAD TO COCKPIT

Get connected.

These steps apply to the Mac package. Windows users: follow the Windows setup and recovery guide.

  1. 01

    Install Companion

    Quit X-Plane, then Companion. Install the package and open the app from Applications. Review and grant the required macOS permissions.

  2. 02

    Update the plugin

    Choose your X-Plane folder in Setup, then Install / Update Plugin. Do this even when upgrading an existing Companion installation.

  3. 03

    Set up your displays

    Create the monitor before launching X-Plane. Select it in Graphics, then use Open Missing Displays. Leave the mouse untouched while setup finishes.

  4. 04

    Connect your headset

    Start Sharing, allow Outside View and approve the headset address. Use port 49200 for displays, then reconnect the headset viewers.
